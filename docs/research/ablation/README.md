# ChromaDB Ablation 실험 설명

실험 실행일: 2026-05-20

본 실험은 NutrAI의 RAG 기반 개인 맞춤 식단 추천 과정에서 다단계 안전 제약이 검색 후보 품질에 어떤 영향을 주는지 평가하기 위한 ablation 실험이다. 실험에는 실제 로컬 ChromaDB의 `nutrition` 컬렉션과 런타임 RAG 파이프라인에서 사용하는 KR-SBERT 임베딩 모델을 사용하였다.

중요한 범위 제한: 본 실험은 결정론적인 후보 단위(candidate-level) 실험이다. Ollama를 호출하지 않으며, LLM이 생성한 최종 문장 품질을 평가하지 않는다. 따라서 본 결과는 사용자에게 표시되는 최종 답변 품질 전체가 아니라, 검색된 추천 후보의 안전성 및 제약 충족도에 대한 결과로 해석해야 한다.

## 실험 조건

| 코드 | 조건 | 검색 단계 알레르겐 필터 | 후처리 칼로리 검증 |
| --- | --- | --- | --- |
| C1 | Baseline | 미적용 | 미적용 |
| C2 | 검색 단계 알레르겐 필터만 적용 | 적용 | 미적용 |
| C3 | 후처리 칼로리 검증만 적용 | 미적용 | 적용 |
| C4 | Full | 적용 | 적용 |

## 실험 결과 요약

| 조건 | 안전 통과율 | 알레르겐 위반율 | 칼로리 위반율 | 시나리오 안전율 | 제약 적합률 | 품질 점수 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| C1 Baseline | 0.8625 | 0.1000 | 0.0375 | 0.6875 | 0.6125 | 80.25 |
| C2 검색 단계 알레르겐 필터만 적용 | 0.9625 | 0.0000 | 0.0375 | 0.9375 | 0.6125 | 84.75 |
| C3 후처리 칼로리 검증만 적용 | 0.9000 | 0.1000 | 0.0000 | 0.7500 | 0.6375 | 82.81 |
| C4 Full | 1.0000 | 0.0000 | 0.0000 | 1.0000 | 0.6375 | 87.31 |

품질 점수는 실험 스크립트에서 다음과 같이 정의하였다.

```text
quality_score = 45% safety pass + 35% constraint fit + 20% coverage
```

Full 조건(C4)은 16개 테스트 시나리오 전체에서 알레르겐 위반과 칼로리 위반을 모두 제거하면서 후보 coverage 100%를 유지하였다. 또한 Baseline(C1)의 품질 점수 80.25보다 높은 87.31을 기록하였다.

다만 C4는 Baseline보다 평균 검색 거리가 소폭 증가하였다. 따라서 본 결과는 순수한 의미론적 관련성 향상이라기보다, 안전성과 제약 충족도를 개선하는 과정에서 나타난 safety-quality trade-off로 해석하는 것이 타당하다.

## 재현 방법

프로젝트 루트(`C:\Users\user\NutrAI`)에서 다음 명령을 실행한다.

```bash
.venv\Scripts\python ai\scripts\ablation_experiment.py
```

## 생성 파일

- `ablation_results.json`: 실행 메타데이터, 실험 조건 정의, 요약 결과, 시나리오별 trial 결과
- `ablation_summary.csv`: 조건별 집계 지표
- `ablation_trials.csv`: 시나리오 단위 지표
- `ablation_candidates.csv`: 감사 및 확인을 위한 선택 후보 행

## 교수님 검토 시 참고할 점

이 실험 결과는 논문 표와 결론에 사용된 수치의 근거 파일이다. 다만 최종 LLM 응답 문장, 실제 사용자 만족도, 맛/가격/조리 가능성 같은 주관적 선호 요인은 평가 범위에 포함하지 않았다. 논문에서는 이 점을 한계로 명시하였다.
